NORTHSTAR CONNECT v0.6.0 — FULL SOURCE PROJECT

Included:
- Existing collaborative canvas, room chat, shared photos, Android widget, and JARVIS read-only viewer
- Account registration/login with random stable Account ID and Argon2id password hashing
- Android Keystore AES-GCM encryption for locally stored bearer session tokens
- Friend requests, accepted friend list, direct and room invitations, persisted inbox
- FCM account notifications and backend-capability-aware WorkManager polling fallback
- Short-lived one-time signaling tickets and friend-only WebSocket signaling
- Browser-to-browser WebRTC DataChannel direct-message test on /friends.html (keepalive + presence refresh)
- Android one-tap launch of /friends.html for browser-based P2P testing (requires sign-in in the browser as a separate session)
- STUN by default and optional TURN via environment variables

Important scope boundary:
- Android account/friend/invite UI is implemented, but native Android WebRTC DataChannel is not yet implemented.
- Browser DataChannel demo sends direct test messages between browsers. Shared canvas and room chat remain on the server WebSocket in this release.
- Signaling presence/tickets are in-memory; deploy one Uvicorn worker until a shared store is added.
- Existing room codes are not yet bound to accounts.

Preserve on update: .git, backend/data, backend/.venv, android/app/google-services.json, and local private config.

v0.6.1 Windows desktop addition:
- Added a Tauri 2 Windows desktop shell in windows-client/.
- Bundles the shared canvas, Friends/accounts page and J.A.R.V.I.S. viewer from web/.
- Desktop backend URL is configurable from the top bar and checked through GET /health.
- Friends REST calls and signaling WebSocket use the selected backend URL.
- .github/workflows/windows-client.yml builds the Windows NSIS setup executable and app binary on a Windows GitHub Actions runner.
- The Windows application source is included; no compiled Windows executable is included in this ZIP because this workspace does not have the Windows/MSVC build toolchain.
